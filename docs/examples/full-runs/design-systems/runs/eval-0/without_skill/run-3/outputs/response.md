# Icon Set Guidelines for Your Startup

## Base Size & Scale Strategy

Start with **24px as your base icon size**—it's the sweet spot for UI icons. This gives you enough detail for your product interface without being oversized. For additional sizes, restrict yourself to **multiples of 8**: 16px (smaller), 24px (base), 32px (larger), and 48px only if marketing icons specifically need extra detail.

Don't create every size upfront. Build 16/24/32 initially; add 48px only when specific glyphs require more breathing room. This keeps your production workflow lean.

## Color Treatment

- **Product UI icons**: Stick to exactly **1 color**. This keeps icons lightweight, scannable, and harmonious in dense interfaces.
- **Marketing icons**: Allow up to **2 colors maximum**. Three or more colors reads as illustration rather than icon and breaks visual cohesion at small sizes.

## Stroke Weight & Gaps

- **Uniform stroke weight**: Every stroke in your set must use the same weight. Mixing strokes weakens visual consistency.
- **No mixing filled and stroked icons** side-by-side unless it's intentional and tied to information hierarchy (e.g., unfilled = inactive, filled = active).
- **Gap between strokes**: The space between parallel strokes must be at least as wide as the stroke weight itself. This prevents crowding and keeps icons legible at small sizes.

## Production Workflow: Build Large, Simplify Down

This is critical: **Always design the largest size first**, then simplify down to smaller sizes. Never start small—details that work at 32px often clutter 16px.

1. Design the 32px version with full detail and spacing
2. Simplify for 24px: remove unnecessary detail, tighten spacing slightly
3. Further simplify for 16px: only essential forms, adjust strokes if needed for legibility

At each step, snap to your pixel grid and check the icon at actual size on screen. What looks good at 100% zoom often fails at 1:1 screen size.

## Deliverables Checklist

- Icon grid (8px grid system)
- Stroke weight specification (e.g., 1.5px, 2px)
- Master file with 32px source art
- Exported sets at 16/24/32px in your preferred formats (SVG, PNG)
- Quick reference showing do's and don'ts for color and complexity
